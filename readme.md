# Kanban
  Esse projeto tem o intuito de ser um aplicativo de Kanban para o gerenciamento de tarefas de empresas. O aplicativo possui diversas funcionalidades, como criar tarefa, criar usuário, atualizar e deletar as tarefas.
# Membros:
 Gabriel Kyochi Bernardes
# As funcionalidades do Kanban são:
- Criar tarefa
- Atualizar tarefa
- Deletar tarefa
- Criar usuário
- Visualizar as informações da tarefa
